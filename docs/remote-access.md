# Codex 远程接入

团队模式下可选的 MCP Streamable HTTP 接口，默认关闭。与内置 AI 独立，不需要在服务器安装 Codex，也不调用 BD 配置的模型。使用者自己的 Codex 处理模型请求；BD 只提供获授权资料和草稿服务。

## 使用方式

1. 部署团队模式，配置 HTTPS 与 `BD_PUBLIC_URL`，按邀请流程创建账号并完成密码、TOTP 设置。远程接口使用 BD 网站的 HTTPS 地址和端口。
2. 管理员进入「管理中心 → AI 设置 → 外部 AI 工具」，开启全局功能；管理员自动具备接入资格，无需为自己单独授权。普通成员默认不允许，在「成员与权限」邀请或调整时勾选「允许连接外部 AI 工具」。功能关闭时也可以预先分配权限，但不能连接或生成凭据。
3. 成员登录「我的账号 → AI 工具连接」，生成个人凭据。邀请只分配权限，不生成、共享或在邀请链接中附带工具凭据。默认仅查询、有效期 7 天；可选查询和提交草稿，有效期最多 30 天，每个成员最多 5 个有效凭据。只读成员只能查询。
4. 凭据只显示一次，服务端仅保存 SHA-256 摘要。将其保存在本人电脑上的环境变量 `AIRALOGY_BD_TOKEN`，使启动 Codex 的进程能够读取。不要把值输入模型对话、代码、网页 URL、共享配置或服务器访问日志。macOS 图形应用不一定继承终端变量，连接前需确认所使用的 Codex 进程确实能读取该变量。
5. 按 [Codex 官方 MCP 文档](https://learn.chatgpt.com/docs/extend/mcp) 配置连接；当前使用个人 Bearer 凭据，不实现 OAuth 登录。

```toml
[mcp_servers.airalogy_bd]
url = "https://bd.example.com/api/mcp"
bearer_token_env_var = "AIRALOGY_BD_TOKEN"
```

CLI 也可以通过 `codex mcp add airalogy_bd --url https://bd.example.com/api/mcp --bearer-token-env-var AIRALOGY_BD_TOKEN` 添加。地址换成自己的 BD 域名，凭据不能共用。重新连接后，可让 Codex 查询某个事项或整理一次实际进展。

提交草稿后，Codex 获得草稿编号和 `/remote#draft-...` 路径。本人进入 BD「待确认修改」，刷新，核对事项、日期、事实状态与全部前后差异，勾选确认，再点击「确认并正式保存」。可以驳回；需修改草稿时先驳回旧稿，再让 Codex 重新提交。

## 功能范围

| 工具 | 能力 |
| --- | --- |
| `search_matters` | 按名称搜索本人获授权的已有事项，20 条一页 |
| `read_matter` | 读取一个获授权事项的正文、阶段、跟进状态、下一步、参与人 ID、版本及进展摘要（分页） |
| `read_progress` | 读取某事项下的一条进展正文及字段 |
| `submit_draft` | 对已有事项新增进展、修改已有进展，或修改事项正文、阶段、跟进状态、下一步及日期 |

新建事项、人员总库、联系方式字段、附件、删除、跨事项关联、账号管理、模型密钥、备份与直接保存不在远程工具中开放。正文中由业务人员自行写入的敏感信息仍会随正文返回；模型服务的数据使用政策仍需符合公司的要求。客户端的工具审批提示只是额外保护，不能替代服务端权限。

修改前须读取当前记录版本；`submit_draft` 的 `revision` 使用该版本，`request_id` 使用唯一 UUID。相同凭据、相同请求编号、相同内容的重试只返回原草稿收据；同编号不同内容拒绝。已保存收据不会再次执行。草稿最长保留 24 小时且不超过凭据有效期。每人最多 20 份待处理草稿，全局最多 2000 份有效期内收据；超限先处理或等待失效。每个账号每分钟最多 60 次接入认证/服务调用，工具调用包含入口校验和执行校验两次。

## 权限与保存保障

- 管理员开关和成员授权使用账号登录、TOTP、CSRF 与管理员权限。邀请与外部工具授权在同一事务中保存；调整成员权限检查资料版本，尚未接受的邀请保留原链接和到期时间。成员自行签发凭据，管理员可以撤销任何凭据；成员只能撤销自己的凭据。
- 管理员的接入资格随角色生效，不保存为普通成员授权；改为普通成员时默认不保留，可按需重新授权。资格本身不会开启全局功能、生成凭据或绕过草稿确认。
- 每次请求检查全局开关、授权、账号启用状态、账号权限版本、凭据有效期和具体事项权限。修改权限、停用账号、重置登录将撤销该成员凭据和草稿；取消远程授权也会撤销。退出网页登录不会撤销已签发的独立远程凭据，请在凭据列表撤销。
- 关闭功能撤销全部凭据与草稿，保留成员授权；重新开启后必须重新生成凭据。个人凭据不具备网页会话权限，不能调用网页确认接口；网页 Cookie 也不能充当 MCP 凭据。
- 草稿绑定提交账号、凭据和权限版本，只能由同一账号在网页确认，管理员不能代替他人确认。确认时再次检查权限、草稿有效期和原资料版本。
- 所有操作经过同一工作区锁；正式保存复用数据服务、事务日志、版本记录和审计。确认接口只取服务端保存的草稿，忽略客户端额外提交的业务字段。确认一次后不能重放。
- 保存前先将草稿标记为处理中；若进程在文件保存和收据更新之间中断，不能盲目重试。先在工作台及历史中检查是否已保存，再决定是否重新整理。并发冲突或保存失败后需读取最新资料并重新提交草稿。
- 管理员可在“修改历史”中比较并恢复资料。恢复本身产生新记录，并检查当前版本；恢复前需要核对是否影响后续人工修改。回退不能撤回已发送给模型的内容，因此不作为开放直接保存的依据。

远程设置、哈希凭据和短期草稿保存在私有 `.bd-auth/accounts.sqlite3`（目录 0700、文件 0600），不进入代码仓库或业务内容历史。草稿正文按业务数据保护，不宣称数据库静态加密。账号备份清除远程设置、普通成员授权、凭据、草稿及限流状态，恢复后默认关闭；审计保留操作类型、账号、凭据/草稿编号和结果，不包含原始凭据或草稿正文。Codex 模型费用不计入内置 AI 用量报表。

## HTTP 协议与运维

`/api/mcp` 提供无会话的 JSON 响应式 Streamable HTTP，支持协议版本 `2025-03-26`、`2025-06-18`、`2025-11-25`；无需长连接。初始化、列工具、调用工具及通知均要求有效凭据。GET/DELETE 在校验授权后返回 405，不提供 SSE、资源订阅或服务端推送。批量 JSON-RPC 请求不支持。

接口检查 Host、Origin（存在时）、请求格式、协议版本、24 KB 请求上限，且不允许跨站请求。网页登录独立执行 CSRF 校验。反向代理只转发到本机应用端口，按部署示例设置登录/请求限流，并对 `/api/mcp` 限制连接数和请求速率。代理必须保留正确 Host、Authorization，禁止记录 Authorization/Cookie。无需把 `.bd-auth`、数据目录或管理端口暴露到互联网。

接口遵循 [MCP Streamable HTTP 规范](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)。自动测试覆盖真实 HTTP、邀请时分配外部工具权限、待激活成员权限调整、TOTP 会话、默认关闭、角色/事项边界、凭据生命周期、草稿确认、重放、并发冲突和停用。每次部署后仍需使用本人账号，按上述步骤完成实际客户端连接验收。
