# 事项与沟通进展回收站

仅管理员可将事项或沟通进展移入回收站并恢复。本机单人模式由本机使用者操作。普通编辑成员可以继续编辑获授权事项，只读成员只能查看。

- 事项详情 → 更多 → 移入回收站。
- 沟通进展详情底部 → 更多操作 → 将此进展移入回收站。
- 管理中心 → 回收站：查看原文、实际操作账号与时间，或恢复记录。可选择同时查看已恢复的记录。

移入前展示事项或进展名称、关联进展、附件及会后补充数量。移入后不再显示在正常列表、时间线、日历、导出和统计中。原文、日期、参与人、原记录更新人、会后补充及修改历史保持不变；操作本身不产生新的业务活动日期。一个事项的所有进展均被移入后，该事项没有最近业务活动日期。

共享的人员、对接方和附件不会删除。资料仍通过其他有效关联事项使用，访问权限继续检查文件原有的全部事项关联。历史快照按快照当时的回收站状态展示。

恢复事项会重新显示其中未被单独移入回收站的进展。此前单独移除的进展需单独恢复；如果所属事项也在回收站，先恢复事项。本功能不提供永久删除、自动清空或 MCP 删除操作。合作暂停、终止应调整事项状态，保留业务记录。

服务在工作区统一事务及历史快照中保存 `content/recycle-bin.yaml`，原始业务文件保留在原处。所有变更校验最新版本，重复请求不会重复执行，操作账号由登录会话确定。回收站索引与业务资料一起备份，不应手动改写。

将错误登记为进展的会后文案改为补充时，先在原会议下保存并核对完整补充内容和日期，再由管理员将重复进展移入回收站。
