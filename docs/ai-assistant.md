# 可选 AI 助手

AI 默认关闭。管理员在「管理中心 → AI 设置」中选择服务、填写模型名称和密钥、设置每日请求上限，再明确开启。本地模式由本机使用者管理配置。关闭后不调用模型，资料管理、账号权限和备份可独立使用。

## 使用

AI 助手页面仅提供对话录入与总结；模型密钥、限额及公司用量集中在 `/admin` 管理中心。团队模式中服务器检查管理员身份，普通成员直接访问管理页会返回工作台，配置及用量接口也会拒绝非管理员。已保存密钥不向任何浏览器回传，管理员只能替换或清除。

- **对话录入**：选择已有事项或让对话识别归属，描述真实进展。缺少日期、事项归属等信息时先追问。管理员也可新建事项和对接方。每次只整理一条事项或进展；多条事项分次确认。
- **确认保存**：页面显示完整草稿，支持继续对话修正或放弃。只有点击「确认无误并保存」才写入；保存仍通过工作台数据服务校验和留存修改历史。预览后有人修改同一事项，会提示重新整理，不能静默覆盖。新草稿替代同一对话中的旧草稿，确认请求只能消费一次；超时或保存失败后，先检查当前资料，再重新整理。
- **进展总结**：选择日期范围（初始为最近七个自然日）和事项，输入问题。仅总结范围内的进展标题、摘要、日期和参与人，每条总结提供服务器解析的来源按钮。没有记录时直接提示，不调用模型。总结范围不包含独立的公司动态、附件或会议全文，也不生成未来建议。
- 编辑成员只能在已授权事项里添加进展；只读成员只能总结；新建事项沿用管理员权限。新建事项默认负责人待确认、优先级中；未提供首次接触或来源时保留未知。参与人姓名保留在正文，系统不自动新建人员档案或推断其事项关系，可保存后由管理员补充。
- 当前对话不会在刷新后恢复到页面。服务器暂存的对话与待确认草稿有效期为 30 分钟，后续请求清理过期记录。权限或 AI 配置变化后，旧对话和草稿不可继续使用。总结只保存在当前页面。

## 模型服务

服务端通过 OpenAI-compatible Chat Completions 接口调用模型，服务商差异封装在 `dashboard/app/lib/ai-provider.ts`。运行 AI 助手无需部署网关、向量数据库或独立代理服务。

| 服务 | 地址 | 模型配置 |
|---|---|---|
| OpenAI | `https://api.openai.com/v1` | 填写本公司账户已开通、支持 Chat Completions JSON mode 的文本模型 ID |
| Qwen 中国区（百炼北京） | `https://dashscope.aliyuncs.com/compatible-mode/v1`，或 `https://<业务空间ID>.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` | 默认 `qwen-plus`，可填写账户已开通且支持 JSON mode 的 Qwen 文本模型 |

服务地址仅允许上述官方 HTTPS 域名和固定路径，不接受任意代理、内网地址或重定向。切换服务或地址后必须填写对应密钥；密钥不回传浏览器。Qwen 使用 `enable_thinking: false` 和 `max_tokens: 4000`；OpenAI 使用 `max_completion_tokens: 8000`、`store: false`。不传采样温度，减少不同模型间的参数差异。不同账户和模型的访问权限、配额、网络可达性需要实际配置后确认。

两个服务都使用 JSON mode；程序严格检查输出字段类型、长度、允许值、人员与事项引用、日期及来源。模型没有可调用的保存、文件、账号或网络工具。拒绝、截断、畸形输出、超时均返回错误，不写业务资料，也不把服务商原始错误或推理内容回显给成员。`store: false` 不等于服务商的零留存承诺；外部服务的数据政策由管理员另行选择并核实。

接口依据：[OpenAI JSON mode](https://developers.openai.com/api/docs/guides/structured-outputs#json-mode)、[百炼 OpenAI-compatible Chat API](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)。配置可使用上表列出的北京地域通用地址或业务空间专属地址。

## 权限与资料处理

权限判断在服务器和数据服务完成，不依赖提示词。调用前只读取当前账号有权访问的事项；不会自动读取人员档案中的电话、微信、邮箱字段，也不读取附件原文、账号配置或密钥。用户输入及授权事项摘要中已有的内容会发送至所选模型服务，页面在开启配置时明示这一点。

模型请求期间发生权限撤回、内容修改或配置变化，结果被丢弃并提示重试。保存时再次经过数据服务的权限检查、事项版本校验、事务锁和录入账号审计。返回的来源 ID 必须匹配本次授权范围，由服务器转换成现有事项/事件，不使用模型生成的网址。

模型仍可能误读业务事实；预览和来源便于人工核对，程序不能自动证明每一句自然语言都正确。保留“准备签署”“尚未付款”等状态区分，不自动把建议变成事实。

## 管理员用量与费用

「管理中心 → 用量与费用」只允许管理员查询，按日期、成员、服务商和模型统计请求次数、失败/中断数、输入 Token、输出 Token、缓存命中与估算人民币费用。计量读取服务商响应中的 `usage`，不会用字符数冒充实际 Token。输出 Token 已包含服务商计入的推理消耗，不另加一次；缓存 Token 已包含在输入总数中，计费时单独按缓存单价处理。统计记录不包含提示词或回复正文。

管理员填写输入、输出和可选的缓存输入单价，单位为人民币元 / 百万 Token。美元报价需自行换算；本功能不拉取价格或汇率，也不假设折扣、税费、阶梯价格和账户账单完全一致。每次调用保存当时单价，之后改价不重算历史。未配置价格显示未计价，不视为免费。切换服务或编辑模型名称时，页面清空单价，要求重新核对。

默认每日 100 万 Token，支持配置公司每日 Token 与费用上限。调用前按本次文本字节数加消息开销、模型最大输出量保守预留额度；这只是防超额预留值，不展示成实际消耗。回传用量后改按实际 Token 和当时单价计入。每位成员最多一个在途请求、全公司最多四个，额度检查与预留在数据库同一事务中完成。

超时、异常退出或未回传 usage 时标为未知，保留该次预留量占用限额，不假装零消耗；两分钟后仍未完成的在途记录标为中断。今日存在未配置价格的旧请求时，不能证明费用额度剩余量，开启费用上限会暂停新的调用；核对账单后可先使用 Token 上限，或次日再按费用额度使用。服务商计量、价格或网络异常仍可能造成估算偏差，账户侧额度也应设置。

## 私有配置与备份

运行状态位于业务工作区的 `.bd-ai/`，不在 `content/` 或生成数据中。目录权限 `0700`、数据库权限 `0600`；API 密钥及暂存对话使用 AES-256-GCM 加密。服务器模式从 `BETTER_AUTH_SECRET` 派生独立用途密钥，本地模式使用该目录下权限 `0600` 的随机密钥。目录内自带忽略规则，初始化和恢复工作区的根忽略文件也排除它。

完整业务 ZIP/OSS 备份**不包含 AI 设置、模型密钥、用量或待确认草稿**。恢复后 AI 默认关闭，需要管理员重新配置。模型密钥应另外保存在公司密码管理器中；更换 `BETTER_AUTH_SECRET` 前要确认可重新提供模型密钥。服务器原卷的 `.bd-ai` 会跨容器重启保存。

默认公司每日最多 100 次模型请求，可设 1–1000 次，按工作区时区计数，失败请求也计入；每位成员每分钟最多 10 次。调用最长 60 秒，限制输入范围和输出大小，不自动重试，避免重复计费。请求次数限制与 Token / 费用限制同时生效，任一限制不足都阻止新的模型请求。数据超过单次范围时要求缩小事项或日期范围，不静默截断成不完整的总结。

## 验证范围

自动测试使用虚构资料与模拟的两家模型响应，覆盖默认关闭、管理员配置、加密和密钥隐藏、官方域名限制、鉴权与 CSRF、只读/编辑/管理员权限、授权范围、来源验证、预览不写入、单次确认、并发确认、过期/失效草稿、并发修改、权限撤回、请求/Token/费用限额、单价快照、缓存计价、未知用量、管理员统计、停用及备份恢复。普通用户、模型或浏览器传入的保存载荷不会替换服务器保管的确认草稿。

没有使用真实公司资料调用外部模型。真实 API 凭据、模型账户权限、网络和语义生成质量需要管理员配置后用非敏感样例验证；模拟响应通过不代表真实模型回答已经验证。
