# 投资问答库

用于积累投融资交流中反复出现的问题，持续完善团队的推荐回答。入口位于工作台的「投资问答」。功能不依赖内置 AI，也不需要配置模型密钥。

## 使用流程

1. 按关键词、分类或回答状态搜索，先查看已有问题及其他常见问法，避免重复建档。
2. 新增问题，填写简短回答、详细 Markdown 回答及明确的数据截至日期。没有答案时也可先记录问题；不要把录入日期当成数据日期。
3. 关联来源事项、具体交流或已有文件版本。也可在沟通记录中点击「整理到投资问答」，先搜索已有问答，再关联本次交流或新建。
4. 编辑成员保存修订稿。管理员阅读「当前修订稿」后点击「确认为推荐回答」，团队即可使用新版本。仅保存不会覆盖原推荐回答。
5. 数据或口径需要更新时，标记「待更新」。历史可查看之前的内容，或恢复为新的修订稿；恢复不自动更换推荐回答。

每条问答包含问题、其他常见问法、分类、简短回答、详细回答、数据截至日期、来源和参考文件。系统记录实际修改人、确认人及时间。空答案不能确认为推荐回答。确认过的回答可以复制；问答不自动生成对外承诺。

历史会议记录保持原样，问答的后续优化不会改写当时的沟通内容。参考文件只关联归档版本，不产生重复附件。

## 权限

「成员与权限」中的「允许访问投资问答库」独立于事项范围。勾选全部事项不会自动获得问答权限。

| 身份 | 问答权限 |
| --- | --- |
| 管理员 | 全库查询、修订、确认推荐版本、归档及恢复 |
| 获授权编辑成员 | 查询推荐回答与修订稿，新增、修改、标记待更新、查看历史和恢复修订稿 |
| 获授权只读成员 | 查询问题及推荐回答；不可查看未确认答案或修订历史 |
| 未获授权成员 | 不显示入口，接口拒绝访问 |

问答正文面向所有获准访问问答库的成员。不要把仅可在某个事项内共享的原文直接复制到团队问答中。来源链接和参考文件仍须具备原事项权限；无权访问的来源不会返回标题、编号或文件名。编辑可见内容时，不可访问的关联仍保留。

归档为可恢复操作，管理员可在「已归档」筛选中查找并恢复。普通只读成员不能查询归档问答。成员授权变更立即撤销既有会话、工具凭据与待确认草稿，重新登录后按新权限访问。

## MCP

成员须同时具备外部工具和问答库授权，再在「我的账号 → AI 工具连接」勾选「允许访问投资问答库」。已有凭据不自动扩大权限；本人可为某条连接单独授权。

| 工具 | 用途 |
| --- | --- |
| `search_investment_qa` | 搜索问题、常见问法和有权查看的答案；每页 30 条 |
| `read_investment_qa` | 读取问答及当前 `revision`；新建时用空 `id` 取得创建版本 |
| `investment_qa_history` | 可写连接查询修订历史；传返回的 `version` 查看历史内容 |
| `submit_investment_qa` | 提交问答修改草稿，本人网页确认后才保存修订稿 |
| `save_investment_qa` | 管理员明确允许直接保存的连接，直接保存修订稿 |

先搜索、再读取版本，最后提交明确的字段修改。`changes` 为部分更新；来源和文件列表替换当前可见关联，无权查看的关联仍保留。相同问题或常见问法会被拒绝，近义问法仍须由使用者判断是否合并。

两种写入工具均不能确认推荐回答、归档、删除或调整权限。新建及编辑使用唯一 `request_id`；重试保持工具、编号和内容完全一致，只返回原处理结果。版本过期须重新读取并合并；不能直接换编号覆盖。结果不确定时先查询问答与历史。

MCP 待确认草稿与网页「问答修订稿」不同：前者最长保留 24 小时，尚未进入资料库；后者已保存为业务资料，并留存历史。网页确认 MCP 草稿后也不会自动确认推荐回答。

## 存储与备份

问答保存为 `content/investment-qa/<问答 ID>/draft.md`，推荐回答保存为同目录 `recommended.md`，均为带 YAML 信息的 Markdown。写入沿用工作台文件锁、校验、原子提交和修改历史。备份包含问答内容及成员的问答库授权，不携带可继续使用的工具凭据。

问答内容通过独立授权接口提供，不写入通用看板的生成数据。`pnpm validate` 同时校验问答资料结构。
