# 界面排版规范

Airalogy BD 使用系统无衬线字体：优先采用操作系统界面字体，并提供苹方、微软雅黑和 Noto Sans 中文回退。不加载外部字体。代码和连接配置使用等宽字体。

字号和行高在 `dashboard/app/typography.css` 统一定义，页面组件引用这些变量。以浏览器默认 16px 为基准，使用 rem 单位，支持用户调整文字大小。

| 用途 | 字号 | 行高 |
| --- | --- | --- |
| 页面标题 | 28px | 1.35 |
| 弹窗标题 | 24px | 1.35 |
| 区块标题 | 20px | 1.35 |
| 分组标题 | 16px | 1.35 |
| 正文、输入、按钮、导航 | 14px | 1.5–1.6 |
| 说明、紧凑表格内容 | 13px | 1.6 |
| 时间、标签、次要信息 | 12px | 1.5–1.6 |
| 业务长文本 | 14px | 1.75 |
| 概览关键数字 | 32px | 1.2 |

同类元素在不同页面共用字号，不通过不断增加字号区分信息层级；辅助信息优先用字重、颜色和间距区分。手机端通过换行、单列布局和表格横向滚动适配，不缩小正文。主要表单的手机端输入字号为 16px，避免聚焦输入时触发浏览器自动缩放。

公司标识位于应用最上方，工作区导航和账号操作在同一栏；「待确认」作为头像旁的操作入口，有草稿时显示数量，没有时弱化显示；页面标题、页面操作和局部导航位于下方。管理中心负责全局配置和成员权限；个人连接由成员在“我的账号”管理。

导出报告有独立的纸张与排版要求，使用报告组件的专用字号，不随界面字号批量调整。

业务总览的“最近进展”默认按事件发生日期倒序展示当前权限和筛选范围内的最近 6 条进展，包含普通和重要事件；重要事件显示“重要”标签。“仅看关键”仅筛选该预览列表，“查看全部”仍展示当前范围的完整时间线。
